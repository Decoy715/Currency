- Учебный проект: `C:\Users\feshi\currency`, код в `src/currency/`. Репозиторий: github.com/Decoy715/Currency

## Пройдено: этап 0 (фундамент)
1. uv-проект, httpx, запрос к API ЦБ РФ (`https://www.cbr-xml-daily.ru/daily_json.js`), разбор вложенного JSON.
2. Функция `get_rates(codes: list[str])`, цикл, проверка `in`, f-строки, подсказки типов, `raise_for_status()`.
3. Git и GitHub: config, коммит, remote, push.
4. Ветки и pull request, README.
5. pydantic: модель `Currency`, методы `rate_per_unit` и `convert`, `**` распаковка словаря, ошибки валидации.
6. async: `history.py`, `httpx.AsyncClient`, `asyncio.gather`, обработка 404 через `try/except httpx.HTTPStatusError`.
7. Docker: Dockerfile с uv, `.dockerignore`, кэш слоёв, `docker build` / `docker run`.

Слабые места, на которые стоит обращать внимание: вложенные структуры и классы/self пока требуют каркаса; путал строку-адрес с запросом при `await`.
